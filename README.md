This Python program is a Smart Restaurant Ordering System that allows customers to select food items and quantities from a menu.
 It stores the selected items in a cart and calculates the subtotal of the order.
 The program adds 5% GST to the subtotal and calculates the final bill amount.
 It also handles invalid inputs and empty orders using basic error handling.
 Overall, it demonstrates the use of lists, dictionaries, functions, loops, and conditional statements in Python.
